在造的东西

自己每天在用的，或者拿来把某个问题想透的。全部开源在 GitHub。

  • deepseek-monitor

    DeepSeek 用量监控。同一份 Flutter 代码跑在 Android、iOS、macOS、Windows、Linux 和浏览器上，桌面端带小组件。

    Dart六端可在线试用

  • easy-captcha

    Spring Boot starter 形式的验证码生成器，靠自动配置接进项目，多种验证码类型开箱可用。

    JavaSpring Boot

  • github-profile-statistics-card

    把多个平台的数据统计渲染成一张卡片，可以直接挂到 GitHub 个人主页 README 里。

    TypeScript服务

  • AnimeTimeline

    用 Python 爬取番剧放送时间表，整理成一份 Markdown 文件。

    Python爬虫

  • ts-tetris-game

    TypeScript 加 HTML5 Canvas 写的俄罗斯方块，经典玩法的一个现代实现。

    TypeScriptCanvas

  • group-avatar-generator

    上传多张图片，自动拼成微信群里那种九宫格群头像。

    TypeScript工具

  • ouchn-course-brusher-script

    基于 Vue 3 和 TypeScript 重构的油猴脚本，面向国家开放大学实验学院的课程页面。

    TypeScript油猴

  • daily-commit-bot

    用 Shell 和 GitHub Actions 搭起来的定时提交小工具。

    ShellActions
